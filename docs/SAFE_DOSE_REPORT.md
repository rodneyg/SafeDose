# SafeDose repository report

Source review at commit `4e0d02db9d90fde2203022650c8412988e582de3`. The test vectors below describe software behavior using synthetic inputs. Packaging and release controls are proposals. For the current scan model, see [the server request](../lib/scan/request.js).

## What the app does

SafeDose converts a user-entered prescribed dose and verified inputs to a calculated volume and syringe marking. Manual entry works offline. The app also includes a [reconstitution planner](../app/reconstitution.tsx) and [dose logging with local storage](../lib/hooks/useDoseLogging.ts). [Offline behavior](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/app/(tabs)/new-dose.tsx#L1074-L1080)

## Computer vision pipeline

```text
User -> Expo app: capture camera frame or choose a photo
Expo app -> Expo app: optional quality check, build image data URL
Expo app -> Vercel: POST /api/analyze-scan with { image }
Vercel -> OpenAI: synchronous vision request after origin, rate and image checks
OpenAI -> Vercel -> Expo app: model JSON text or an error
Expo app -> Expo app: parse, check consistency, map eligible fields
Expo app -> User: review and confirm, retake, or recover in manual entry
User -> Expo app: enter prescribed dose, review calculation, confirm
```

- **On device.** Web capture encodes a canvas frame as JPEG or reads a selected file as a data URL. Native capture uses Expo Camera and can read its file URI as base64. An optional quality precheck can request a retake before upload. Offline, duplicate in-flight attempts and missing guest sessions are handled in the app. The app checks scan allowance and increments usage after successful mapping. [Capture and upload](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/cameraUtils.ts#L111-L179) · [Native capture and quality check](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/cameraUtils.ts#L187-L279) · [Web camera](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/cameraUtils.ts#L323-L350) · [App gates](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/app/(tabs)/new-dose.tsx#L796-L854)
- **On the server.** Vercel serves the Expo web build and routes API calls to Node functions. The scan endpoint validates the data URL and estimated decoded size up to 4 MiB. Its origin check and best-effort per-instance limit of 10 requests per IP per minute provide abuse controls. The client aborts after 20 seconds, including body reads. The server call can outlast that deadline. The server allows 45 seconds for OpenAI with SDK retries disabled. This scan path is synchronous with no durable queue or automatic retry. The user can retake or use manual entry. [Deployment routes](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/vercel.json#L1-L30) · [Scan endpoint](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/api/analyze-scan.js#L5-L98) · [Rate limiter](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/apiRateLimit.js#L3-L47) · [Client transport](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/scan/completeOnServer.ts#L1-L49)
- **Model and parser.** The server calls pinned `gpt-4o-2024-08-06` with temperature 0 and JSON-object output. The same vision call reads printed text, graduations and the leading plunger edge. It asks for between-mark observations, per-field confidence and explicit refusal. The app parses and validates the result. Confidence is supplied by the model and does not establish accuracy. [Model request](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/scan/request.js#L3-L23) · [Response parser](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/scan/index.ts#L44-L109)

## Product and medical boundaries

The README, terms and final review tell users to verify inputs and confirm results against the prescription with a licensed professional. Capacity, amount and volume checks catch arithmetic or input hazards. A plausible but incorrect label reading can still pass these checks, and the software does not verify whether a prescription is clinically appropriate. [README disclaimer](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/README.md#L31-L39) · [Terms](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/app/terms.tsx#L3-L15) · [Final review copy](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/components/PreDoseConfirmationStep.tsx#L41-L113)

## Packaging proposal

**OSS:** Publish a vendor-neutral local package for syntax validation, image quality checks, mock transports and synthetic fixtures, with refusal and review states preserved. Confirm the license and supply the full text before redistribution. The README declares MIT and notes that the repository lacks the full text. [Parser boundary](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/lib/scan/index.ts#L111-L161) · [License note](https://github.com/rodneyg/SafeDose/blob/4e0d02db9d90fde2203022650c8412988e582de3/README.md#L145-L150)

**Pro:** Sell managed integration and support. A partner plugin should receive candidate transcriptions, source location if available, confidence and refusal reasons. Keep review and manual fallback available in every tier. The host owns the review UI, access control and consent. Keep dose calculation, prescription interpretation and clinical record writes outside this proposed SDK interface.

## Existing prices and revenue boundary

The app's Photo Check offer uses web checkout. Guest and unpaid accounts receive three photo scans per month, while Photo Check uses an unlimited scan limit in application logic. Listed prices are **$2.99 per month** and **$26.99 per year**. The calculator is free. These are configured offers, and this report does not calculate or estimate revenue. ## Compliance posture

- **Current.** The first-scan screen explains capture and can be dismissed for future scans. Camera permission and review confirmation serve distinct purposes. The traced flow does not show a separate opt-in for evaluation capture. The privacy notice describes account deletion by request. The scan handler checks origins and has no country eligibility rule.
